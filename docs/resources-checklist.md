- [ ] [Attention Is All You Need (2017)](https://arxiv.org/abs/1706.03762) — Transformer architecture
- [ ] [ReAct: Synergizing Reasoning and Acting (2022)](https://arxiv.org/abs/2210.03629) — agentic loops
- [ ] [RAG: Retrieval-Augmented Generation (2020)](https://arxiv.org/abs/2005.11401) — RAG pattern
- [ ] [Constitutional AI (Anthropic, 2022)](https://arxiv.org/abs/2212.08073) — safety + RLHF
- [ ] [Lost in the Middle (2023)](https://arxiv.org/abs/2307.03172) — long context failure modes
- [ ] [HyDE: Hypothetical Document Embeddings (2022)](https://arxiv.org/abs/2212.10496) — RAG improvement

## Tools to Set Up and Explore

- [ ] [LiteLLM](https://github.com/BerriAI/litellm) — multi-provider LLM proxy, run locally
- [ ] [Instructor](https://github.com/instructor-ai/instructor) — structured outputs from LLMs
- [ ] [RAGAS](https://github.com/explodinggradients/ragas) — RAG evaluation framework
- [ ] [Braintrust](https://braintrust.dev) — evals and tracing
- [ ] [LangSmith](https://smith.langchain.com) — LLM observability (free tier)
- [ ] [Ollama](https://ollama.com) — already running on Mac Studio, explore model library
- [ ] [vLLM](https://github.com/vllm-project/vllm) — production-grade local inference
- [ ] [PromptFoo](https://promptfoo.dev) — prompt testing in CI

## Suggested Order

1. Anthropic Docs (Quickstart → Messages → Tool use → Prompt caching)
2. OpenAI Docs (Chat Completions → Function Calling → Embeddings)
3. DeepLearning.AI: Prompt Engineering → Building Systems → RAG → Agents → Evals
4. Anthropic Courses (GitHub notebooks)
5. Karpathy videos (for internals intuition)
6. Papers (read alongside the relevant phase in learning-plan.md)
7. Books (Chip Huyen — read in Phase 4+)
