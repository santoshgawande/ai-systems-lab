# Lab 01 — Knowledge Graph Entity & Relation Extraction

Extract structured knowledge graphs from unstructured documents to enable multi-hop reasoning.

## What you learn

- How to turn text chunks into Entity-Relation-Entity (E-R-E) triplets
- Graph schema modeling: Entity types, relationship predicates, descriptions
- Multi-hop graph traversal for complex relational queries
- Why standard vector embedding retrieval fails on multi-hop questions

## Run

```bash
python kg_extractor.py
```
