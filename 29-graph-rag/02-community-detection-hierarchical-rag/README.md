# Lab 02 — Community Detection & Hierarchical GraphRAG

Hierarchical knowledge graph clustering and dual-mode retrieval (Microsoft GraphRAG).

## What you learn

- How Leiden/Louvain community detection groups entities into thematic clusters
- Why vector embeddings fail on global dataset-wide summarization queries
- Dual-mode GraphRAG architecture: Local Entity Search vs Global Map-Reduce Search
- Hierarchical community reports (Level 0 Micro -> Level 1 Macro)
