# Lab 01: Model Context Protocol (MCP) Server

## What You Learn
- The JSON-RPC 2.0 wire format underlying the Model Context Protocol.
- Implementing the `initialize` handshake and capability negotiation.
- Exposing tools via `tools/list` and handling execution via `tools/call`.
- Exposing structured file/database context via `resources/list` and `resources/read`.

## Run
```bash
python 01-mcp-server/server.py
```
