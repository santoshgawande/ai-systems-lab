# Lab 02: Preference Dataset Pipeline

## What You Learn
- Building high-quality pairwise preference datasets (`prompt`, `chosen`, `rejected`).
- Combating Verbosity Exploitation (length bias) in RLHF and DPO.
- Margin filtering to eliminate noisy, ambiguous preference pairs.
- Exporting datasets to JSONL for alignment training.
